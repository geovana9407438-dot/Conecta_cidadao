# Planejamento do Conecta Cidadão

## Objetivo

Desenvolver um sistema que permita registrar problemas da comunidade,
acompanhar seu andamento e visualizar quando eles forem resolvidos.

## Etapas do desenvolvimento

1. Definir o objetivo do sistema.
2. Definir o funcionamento do sistema.
3. Criar as telas do sistema.
4. Desenvolver o cadastro e o login.
5. Criar o cadastro de problemas.
6. Desenvolver o Back-End.
7. Conectar o sistema ao banco de dados.
8. Implementar a segurança.
9. Integrar todas as partes.
10. Realizar os testes finais.

## Fluxo do usuário

Usuário
↓
Cadastro ou Login
↓
Tela inicial
↓
Escolher categoria
↓
Cadastrar problema
↓
Enviar problema
↓
Problema recebido
↓
Em andamento
↓
Resolvido
↓
Acompanhar solução
