# Mapa de Integração — Conecta Cidadão

## Como as partes do projeto se conectam

O Conecta Cidadão será formado pela integração das áreas desenvolvidas
pelos integrantes da equipe.

### 1. Front-End

O usuário interage com as telas do sistema.

↓

### 2. Back-End

Recebe e processa as informações enviadas pelo usuário.

↓

### 3. Banco de dados

Armazena as informações necessárias para o funcionamento do sistema.

↓

### 4. Segurança

Protege o acesso e as informações do sistema.

↓

### 5. Aplicativo

A solução poderá ser adaptada para utilização em dispositivos móveis.

↓

### 6. Integração

Todas as partes são reunidas para formar o sistema completo.

↓

### 7. Testes

A equipe verifica se as funcionalidades estão funcionando corretamente.
