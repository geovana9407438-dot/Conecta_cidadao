# Objetivo do Conecta Cidadão

O Conecta Cidadão tem como objetivo facilitar o registro, o acompanhamento
e a resolução de problemas da comunidade.

## O que o usuário poderá fazer

O usuário poderá:

- Criar uma conta;
- Entrar no sistema;
- Escolher uma categoria para o problema;
- Informar qual é o problema;
- Informar onde ele aconteceu;
- Adicionar uma descrição;
- Adicionar uma foto;
- Enviar o problema;
- Acompanhar o andamento da solicitação;
- Ver quando o problema for resolvido.

## Funcionamento do sistema

O sistema seguirá o seguinte processo:

1. O usuário entra no sistema.
2. Faz login ou realiza o cadastro.
3. Escolhe a categoria do problema.
4. Cadastra o problema.
5. Informa o local e a descrição.
6. Envia o problema.
7. O sistema recebe a solicitação.
8. O problema fica como "Recebido".
9. O problema passa para "Em andamento".
10. Após a solução, fica como "Resolvido".
11. O usuário acompanha a solução.

## Problemas que queremos resolver

Muitas pessoas encontram problemas na comunidade, mas não sabem para quem
informar ou não conseguem acompanhar o andamento da situação.

O Conecta Cidadão busca facilitar esse processo, permitindo que o cidadão
registre o problema e acompanhe sua solução de forma organizada.
