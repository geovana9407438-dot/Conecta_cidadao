# Estrutura do Projeto — Conecta Cidadão

## Organização

O projeto será dividido em áreas para facilitar o desenvolvimento e a
integração do sistema.

### Desenvolvimento de Software

Responsável pelo planejamento e pela organização da estrutura do projeto.

### Front-End

Responsável pela parte visual e pelas telas utilizadas pelo usuário.

### Back-End

Responsável pelo funcionamento interno do sistema e pelo processamento
das informações.

### Desenvolvimento de Aplicativos

Responsável pela adaptação e desenvolvimento da solução para aplicativos.

### Fundamentos de Segurança de Software

Responsável pelos cuidados relacionados à segurança do sistema.

## Integração

Após o desenvolvimento de cada parte, os componentes serão integrados
para formar o Conecta Cidadão completo.

## Testes

Depois da integração, serão realizados testes para verificar o
funcionamento do sistema.
