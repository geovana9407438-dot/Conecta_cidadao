# Requisitos do Conecta Cidadão

## Requisitos funcionais

O sistema deverá permitir:

1. Realizar cadastro de usuário.
2. Realizar login.
3. Escolher uma categoria de problema.
4. Registrar um problema.
5. Informar o local do problema.
6. Adicionar uma descrição.
7. Adicionar uma foto.
8. Enviar o problema para o sistema.
9. Acompanhar o andamento do problema.
10. Visualizar o status da solicitação.
11. Identificar quando o problema estiver resolvido.

## Status do problema

O problema poderá apresentar os seguintes status:

- Recebido
- Em andamento
- Resolvido

## Requisitos de organização

O sistema deverá organizar as informações para facilitar o acompanhamento
dos problemas registrados pelos usuários.

## Integração

Depois que cada integrante concluir sua parte, os componentes deverão ser
integrados para formar o sistema completo.

## Testes

Os testes completos serão realizados somente após a integração das partes
do projeto.
