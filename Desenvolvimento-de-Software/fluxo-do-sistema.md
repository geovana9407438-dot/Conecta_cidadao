# Fluxo do Sistema — Conecta Cidadão

## Fluxo principal

INÍCIO
↓
LOGIN OU CADASTRO
↓
TELA INICIAL
↓
ESCOLHER CATEGORIA
↓
CADASTRAR PROBLEMA
↓
INFORMAR LOCAL
↓
ADICIONAR DESCRIÇÃO
↓
ADICIONAR FOTO
↓
ENVIAR PROBLEMA
↓
PROBLEMA RECEBIDO
↓
EM ANDAMENTO
↓
RESOLVIDO
↓
ACOMPANHAR SOLUÇÃO
↓
FIM

## Descrição do fluxo

1. O usuário acessa o sistema.
2. O usuário realiza o cadastro ou login.
3. Na tela inicial, escolhe a categoria do problema.
4. O usuário registra as informações do problema.
5. O problema é enviado ao sistema.
6. O sistema registra a solicitação.
7. O problema recebe o status "Recebido".
8. Depois, passa para "Em andamento".
9. Quando solucionado, recebe o status "Resolvido".
10. O usuário pode acompanhar a solução.

## Objetivo do fluxo

Organizar as etapas do sistema desde a entrada do usuário até o
acompanhamento da solução do problema.
