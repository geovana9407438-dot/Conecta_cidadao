# Objetivo do Conecta Cidadão

O Conecta Cidadão tem como objetivo facilitar o registro e o acompanhamento de problemas.

O usuário poderá informar:

- Qual é o problema
- Onde aconteceu
- Uma descrição
- Uma foto

O sistema permitirá que o usuário acompanhe o problema até sua resolução.

## Problemas que queremos resolver

Muitas pessoas encontram problemas, mas não sabem para quem informar ou não conseguem acompanhar a situação.

O Conecta Cidadão busca facilitar esse processo.
